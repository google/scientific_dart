# code_editor (Experimental)

<img src="doc/images/mascot.png" align="right" width="220" alt="code_editor mascot">

> [!WARNING]
> **Experimental**: This package is an experimental internal component supporting [`package:notebook`](../notebook) and is not intended for standalone production use.

A multi-backend code editor component in Dart supporting syntax highlighting, LSP completions, and HTML/Flutter/terminal rendering backends for the Scientific Dart Notebook environment.
